upload-url.handler.ts TypeScript 
import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';

export const handler = async (event) => {
  const { fileName, mimeType } = JSON.parse(event.body);
  const command = new PutObjectCommand({
    Bucket: process.env.FILES_BUCKET_NAME,
    Key: `users/${userId}/files/${fileName}`,
    ContentType: mimeType,
  });
  const uploadUrl = await getSignedUrl(s3Client, command, { expiresIn: 900 });
  return { statusCode: 200, body: JSON.stringify({ uploadUrl }) };
};

Technical Decisions & Trade-offs

Notes on why this is structured the way it is — API Gateway limits, table design, auth plumbing.

cloud_sync

Direct S3 Uploads

API Gateway has a 10 MB payload limit and buffering large files in Lambda wastes execution time. Instead, the frontend gets a signed S3 PUT URL and uploads directly.

table_chart

Single-Table DynamoDB

Users, folders, and files share one table with composite PK/SK keys. Listing a folder's contents — including breadcrumbs — is one Query call, no joins.

bolt

Angular Signals

State is managed entirely with Signals — no RxJS subscriptions, subjects, or manual unsubscription boilerplate.

security

Cognito JWT Auth

Authentication runs through Cognito User Pools with an Angular HTTP interceptor that attaches JWT Bearer tokens and handles session timeouts.

code_blocks

AWS CDK (TypeScript)

Infra as code via AWS CDK (TypeScript). The whole stack can be deployed from scratch with one command.

verified

Test Coverage

Backend handlers are tested with Vitest against mocked AWS SDK calls. Frontend components and dialogs are covered with Angular TestBed tests.
